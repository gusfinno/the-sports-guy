# the-sports-guy
This is a website for my HSC Software Engineering 2026 Major Work.
It is serving as a prototype for how sports websites should look.
* No gambling adverts
* Results and Information prioritised over pushing news
* Easy access to statistics (including for live events)

## How it works
The website uses a python backend with Jinja2 templating, SQLite for its database and FastAPI to connect the front end with the back end. 
For my sport information I am focusing on F1 since it is in season throughout the entireity of the project and has an abundance of information. Ensuring I picked a sport that was in season throughout the entireity of the project was important since that meant how it looked when I developed it was how it would look when being assessed. It also allowed me to see how the website functioned as results changed week on week.
